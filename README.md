# 📱 SmartStock - Flutter Mobile App

Ứng dụng di động đa nền tảng thuộc hệ sinh thái **SmartStock**, được xây dựng để mang lại trải nghiệm quản lý kho hiện đại, mượt mà và chính xác trên nền tảng Flutter.

## 🚀 Công nghệ sử dụng
* **Framework:** Flutter (Dart) - Biên dịch Native Performance.
* **Giao diện:** Material Design 3 (Google), đảm bảo phản hồi UI 60fps.
* **Quản lý trạng thái:** Provider.
* **Thư viện tích hợp:** VietQR (Tạo mã thanh toán động), Firebase SDK.

## 🛠 Tính năng nổi bật
* **Quét mã QR:** Tích hợp camera giúp nhập/xuất kho nhanh chóng, giảm thiểu sai sót thủ công.
* **Thanh toán VietQR động:** Tự động sinh mã QR chứa đầy đủ số tiền và nội dung chuyển khoản, giúp khách hàng thanh toán nhanh chóng và chính xác.
* **Chat Real-time:** Tương tác trực tiếp giữa khách hàng và bộ phận hỗ trợ thông qua Firebase Realtime Database.
* **Dashboard trực quan:** Thống kê doanh thu, giá trị tồn kho và hiệu suất kinh doanh bằng các biểu đồ sinh động dành cho Admin.
