# 📱 SmartStock - Flutter Mobile App

[cite_start]Ứng dụng di động đa nền tảng thuộc hệ sinh thái **SmartStock**, được xây dựng để mang lại trải nghiệm quản lý kho hiện đại, mượt mà và chính xác[cite: 26, 395].

## 🚀 Công nghệ sử dụng
* [cite_start]**Framework:** Flutter (Dart) - Biên dịch Native Performance[cite: 180, 397].
* [cite_start]**Giao diện:** Material Design 3 (Google), đảm bảo phản hồi UI 60fps[cite: 251, 320].
* [cite_start]**Quản lý trạng thái:** Provider[cite: 106].
* [cite_start]**Thư viện tích hợp:** VietQR (Tạo mã thanh toán động), Firebase SDK[cite: 212, 228].

## 🛠 Tính năng nổi bật
* [cite_start]**Quét mã QR:** Tích hợp camera giúp nhập/xuất kho nhanh chóng, giảm thiểu sai sót thủ công[cite: 153, 401].
* [cite_start]**Thanh toán VietQR động:** Tự động sinh mã QR chứa đầy đủ số tiền và nội dung chuyển khoản, giúp khách hàng thanh toán trong "1 nốt nhạc"[cite: 378, 381].
* [cite_start]**Chat Real-time:** Tương tác trực tiếp giữa khách hàng và bộ phận hỗ trợ thông qua Firebase Realtime Database[cite: 216, 383].
* [cite_start]**Dashboard trực quan:** Thống kê doanh thu, giá trị tồn kho và hiệu suất kinh doanh bằng các biểu đồ sinh động dành cho Admin[cite: 330, 404].
