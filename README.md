# 📱 SmartStock - Flutter Mobile App

Ứng dụng di động trong hệ sinh thái **SmartStock**, giúp quản lý kho hàng mọi lúc mọi nơi thông qua giao diện trực quan và hiệu năng cao.

## 🚀 Công nghệ sử dụng
* **Framework:** Flutter (Dart)
* **Quản lý trạng thái:** Provider
* **Giao diện:** Material Design 3
* **Tích hợp:** Camera (Barcode Scanning), Firebase Cloud Messaging (Nofitications)

## 🛠 Tính năng nổi bật trên Mobile
* **Quét mã vạch:** Sử dụng camera để kiểm kê sản phẩm và nhập/xuất kho siêu tốc.
* **Thông báo đẩy:** Nhận tin nhắn cập nhật trạng thái đơn hàng thời gian thực qua Firebase.
* **Giao diện đa quyền:** Tự động thay đổi giao diện/chức năng dựa trên vai trò người dùng (Admin, Nhân viên, Khách hàng).
* **Trải nghiệm mượt mà:** Tối ưu hóa UI giúp ứng dụng đạt tốc độ phản hồi nhanh trên các thiết bị Android và iOS.
